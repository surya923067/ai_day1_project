# Day 2: Pandas Data Cleaning & LLM Analytics Pipeline

## 🚀 Overview
This project builds an automated data processing pipeline that cleans raw customer records using **Pandas** and integrates with the **Gemini API** to generate structured, human-like business insights and cohort summaries.

## 🛠️ Tech Stack
- Python
- Pandas (Data manipulation & cleaning)
- Google GenAI SDK (LLM Analysis)

## 📂 Files
- `clean_data.py`: Cleans raw customer CSV records and handles missing values.
- `analyze_customers.py`: Sends structured summary data to Gemini API for business intelligence reporting.
