# Day 3: Pure Python Semantic Vector Search Engine

## 🚀 Overview
This project implements the foundational mathematics and logic behind **Semantic Vector Search** from scratch using Python. Instead of relying on exact keyword matching like SQL databases, it demonstrates how text meanings and vector proximity are evaluated to retrieve relevant records.

## 🛠️ Tech Stack
- Python
- Mathematical Logic (Cosine similarity & semantic space mapping)

## 📂 Files
- `vector_search.py`: Core logic script simulating semantic vector search and scoring customer feedback queries by contextual meaning.
